# KMLE QBank · Project Genesis

정적 GitHub Pages 학습 공간. API 키, AI 호출 서버, 계정 가입 없이 사용합니다.

## 학습 공간

- **KMLE**: 문항 JSON 가져오기, 범위별 풀이, 확신도와 간격 복습, 이어풀기, 추론 노트, 북마크, 집중 타이머.
- **학교 블록시험**: 학기/블록별 자료 보관, 블록 안의 여러 시험, 자료별 페이지·슬라이드·시간 범위, 자료 기반 출제 요청문, 원문 검토 후 풀이.
- **실기 연습**: CPX·OSCE·환자 설명 체크리스트, 누락 단계, 관찰 피드백, 연습 방식, 다음 복습일. 학교 평가표를 직접 등록하는 공간이며 수행능력을 자동 평가하지 않습니다.

## API 없는 학교 시험 출제

1. 학교 블록시험에서 블록을 만들고 정리본·기출 PDF·PPT·녹음/전사본을 추가합니다.
2. 시험을 선택하고 출제할 자료를 체크합니다. 각 자료의 포함 구간과 교수님 강조점을 입력합니다.
3. 출제 요청문을 복사하고 자료 묶음 ZIP을 받습니다. ZIP을 풀어 선택한 자료와 요청문을 평소 사용하는 AI에 직접 첨부합니다.
4. AI가 반환한 JSON을 해당 시험에 가져옵니다. 파일명·페이지·정답을 원문과 확인하고 ‘원문과 정답 확인 완료’를 누릅니다.
5. 검토를 마친 문항을 풉니다. 새로 가져온 학교 문항은 검토 전에는 어떤 풀이 세션에도 포함되지 않습니다.

사이트 자체는 PDF/PPT를 읽거나 음성을 전사하지 않습니다. 구간 지정도 원본 파일을 자르는 기능이 아니라 AI에 전달하는 범위 지시입니다. AI 서비스의 파일 지원·구독·사용량 제한이 적용되며, 읽지 못한 파일은 전사본/지원 형식으로 준비해야 합니다. 수업과 임상 기준의 충돌 및 근거 공백은 별도 보고하도록 요청합니다.

## 저장 및 백업

- 기존 `kmle-qbank` IndexedDB v1 / `kv`의 문항, 풀이, SRS 키를 유지합니다. 같은 사이트·같은 브라우저에서 기록을 이어갑니다.
- 노트, 북마크, 세션, 블록 메타데이터, 실기 기록은 `meta.workspace`에 저장합니다. 즉시 새로고침 시 복구용 localStorage journal을 함께 사용합니다.
- 자료 원본은 IndexedDB의 `asset:<source-id>`에 보관합니다. 파일당 최대 100 MB, 브라우저 여유 용량 범위 내입니다. 서버/GitHub로 자동 업로드하지 않습니다.
- **전체 백업 JSON에는 원본 PDF/PPT/녹음이 포함되지 않습니다.** 학교 블록시험에서 필요한 원본들을 선택하여 ZIP으로 별도 내보내세요. 다른 기기에서는 JSON을 병합한 뒤 ‘파일 복원’으로 해당 원본을 다시 선택합니다. 원본 파일명을 유지하세요.
- 브라우저 저장소 삭제나 기기 변경에 대비해 JSON과 원본 파일을 함께 보관하세요. 기기간 자동 동기화는 없습니다.
- GitHub에 `bank.json`을 올리는 기존 문항 동기화 기능은 유지합니다. 공개 저장소에 올린 문항은 공개됩니다. 교수님 자료 원본이나 개인 기록을 저장소에 올릴 필요는 없습니다.
- Genesis 프로토콜 원문은 이 저장소에 포함하지 않습니다. 요청문은 학습을 돕는 보조 양식이며 프로토콜의 공식 최신본을 대체하지 않습니다.

## 개발 및 검증

정적 파일 `index.html`, `workspace.css`, `workspace.js`, `campus.js`를 함께 제공합니다. 빌드나 npm 의존성이 필요 없습니다.

```sh
node tests/regression.cjs
```

Node.js 18+ 및 Python 3으로 범위 분리, 미검토 문항 제외, 백업 병합, 중단된 세션 복구, 중복 제출 방지, 출제 범위 전달, ZIP 무결성과 UTF-8 파일명을 검증합니다. 실제 브라우저에서는 문항 가져오기/풀이/노트/북마크, 새로고침 복원, 자료 보관, 검토 상태, 실기 기록을 확인했습니다. 테스트 문항과 자료는 운영 저장소에 포함하지 않습니다.
